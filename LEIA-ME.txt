ATIVIDADE DE MIGRAÇÃO — PYTHON SIMPLIFICADO, SEM ARQUIVOS .BAT

Os quatro programas mantêm as funções principais dos originais em C,
Java e COBOL. O código utiliza classes básicas, compatíveis com os diagramas.

Programa 1 — Funcionários (C): cadastrar até 100, listar e buscar por nome.
Programa 2 — Alunos (Java): cadastrar, listar e consultar notas.
Programa 3 — Média (COBOL): cadastrar cinco alunos e calcular a média.
Programa 4 — Votação (Java): receber votos de três opções e mostrar totais.

COMO EXECUTAR (VS CODE OU TERMINAL):
1. Extraia TODO o arquivo ZIP para uma pasta (Downloads, Desktop etc.).
2. Abra esta pasta (Entrega_Migracao_Python) no VS Code.
3. No terminal, execute: python executar.py
   Ou, se necessário no Windows: py executar.py
4. Escolha uma opção de 1 a 4 ou 5 (testes).

Para executar sem o menu, por exemplo:
   python codigos/02_alunos_java.py

Para testar diretamente:
   python testes/testar_programas.py

Os dados ficam em memória enquanto o programa está aberto.
Os arquivos SQL e diagramas atendem às etapas de documentação e modelagem.
Não há arquivos .bat nesta versão.
